# Security reports

Do not post private archive data, keys, tokens, credentials or identifying records
in a public issue. Use GitHub's private vulnerability reporting when enabled on
this repository. Reports should use synthetic reproductions and identify the
relevant version, affected entrypoint and expected permission boundary.

This is a single-user self-hosted bridge. It is not designed as a multi-tenant
service. See docs/PRIVACY.md for data flow, key protection and retention limits.
